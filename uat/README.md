# TuxGuitar UAT

User acceptance tests for this fork, as a [Starlight](https://starlight.astro.build) site. Pages live in
`src/content/docs/features/`, one per feature or slice, in the layout described in
`src/content/docs/writing/page-format.md`.

| Command           | Action                                |
| :---------------- | :------------------------------------ |
| `npm install`     | Install dependencies                  |
| `npm run dev`     | Serve the site at `localhost:4321`    |
| `npm run build`   | Build the site to `./dist/`           |
| `npm run preview` | Preview the build locally             |
